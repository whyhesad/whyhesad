## Задача

Представить услуги разработки, показать интерфейсы и дать посетителю понятный способ обсудить проект. Для рекламных переходов подготовлены отдельные страницы лендинга, многостраничного сайта, PWA и Telegram-бота.

## Реализация

- Самостоятельная вёрстка на HTML, CSS и JavaScript.
- Процедурная Three.js-сцена на главной; управление движением и статичный вариант при reduced motion.
- Общий стиль и отдельное предложение для каждой услуги: объём, ориентир цены, сроки, примеры.
- Форма → Cloudflare Worker → Telegram Bot API. Токен находится в серверном секрете.
- Проверка источника запроса, размера и полей; Cloudflare Turnstile.
- Успех отображается после подтверждения Telegram; при сбое текст обращения сохраняется.
- Метрика: переход в Telegram, начало заполнения, подтверждённая доставка. Текст полей исключён из Вебвизора.

## Проверка

Мобильная и настольная вёрстка, переходы, выбор услуги, подготовка сообщения при недоступной отправке. Автоматические проверки серверных ошибок и целей выполняются с подменой внешних запросов.

## Границы

Это мой собственный сайт. Здесь нет заявленных клиентских результатов или выдуманных показателей роста продаж. Код событий Метрики подключён; настройка целей в её кабинете на момент подготовки описания не подтверждена.
